# EzkaVisual

Визуальный мод для Minecraft 1.21.4 на Fabric.

## Возможности

- **ClickGUI** — красивый интерфейс настроек модулей (Panel стиль)
- **Косметика** — кейпы, питомцы, крылья, шляпы, анимации
- **HUD элементы** — виталс, скорборд, таймеры, координаты
- **Рендер эффекты** — Motion Blur, Fog Blur, Trails, Particles
- **Интерфейс** — кастомное главное меню, уведомления, звуки
- **Discord RPC** — отображение статуса в Discord
- **Модули** — Sprint, Zoom, FreeLook, Item Physics,World Module и др.

## Совместимость

- Minecraft 1.21.4
- Fabric Loader 0.19+
- Java 21

## Установка

1. Скачай ezkavisual-fyl1x-2.0.jar из релизов
2. Скопируй в папку mods в .minecraft
3. Убедись что Fabric и Fabric API установлены

## Сборка

`ash
./gradlew build
`

JAR будет в uild/libs/
